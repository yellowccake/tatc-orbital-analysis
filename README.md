# TAT-C Orbital Analysis

Python-based orbital coverage analysis using NASA TAT-C.

This project demonstrates:
- satellite observation window analysis
- Sun-synchronous orbit coverage analysis
- TLE-based orbit propagation
- ground target access calculations

## Tools
- Python 3.12
- TAT-C

## Example
The script simulates a satellite mission and computes observation opportunities over selected ground locations during a 10-day mission window.
